## 🚀 Projetos em Destaque

## 🗺️ Relatório de Performance de Vendas & Roteirização

Solução desenvolvida para acompanhar a operação de vendedores em rota, reunindo informações de **produtividade, cumprimento de roteiro e faturamento**.

O projeto surgiu de uma necessidade real de negócio: entender quanto cada vendedor efetivamente trabalhava, quais rotas estavam sendo cumpridas e qual era o impacto dessas visitas nas vendas.

### Principais recursos

- Acompanhamento de produtividade dos vendedores
- Análise de visitas realizadas
- Monitoramento de cumprimento de rota
- Indicadores de faturamento
- Filtros por vendedor e período
- Visualização de KPIs
- Interface voltada à tomada de decisão

**Tecnologias**

`Power BI` `HTML` `CSS` `JavaScript` `Análise de Dados`

> 🚧 Documentação do projeto em construção.
